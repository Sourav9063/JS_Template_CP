# JavaScript Competitive Programming Template

This repository contains a highly optimized template for Competitive Programming (CP) in JavaScript (Node.js). It provides a fast I/O wrapper and implementations of common data structures and algorithms (STL equivalents) that are missing in standard JS.

## 📂 Project Structure

*   **`main.js`**: The main entry point. Contains the `solve()` function where you write your solution logic, and the `main()` function which handles I/O and test cases.
*   **`helper/`**: Directory containing reusable data structures and algorithms.
    *   `ds.js`: Data structures like `PriorityQueue`, `Deque`, `DSU`, `SegmentTree`.
    *   `math.js`: Math utilities like `gcd`, `lcm`, `power`, `modInverse`.
    *   `graph.js`: Graph algorithms.
    *   `string.js`: String algorithms.
    *   `geometry.js`: Geometry primitives.
*   **`io/`**: Directory for local input/output testing.
    *   `input.txt`: Paste your test case input here.
    *   `output.txt`: The script writes the output here.
*   **`output.js`**: The final bundled file generated by `npm run build`, ready for submission.

## 🚀 Key Scripts

Use `npm` to run the following commands:

*   **`npm run test`**: Runs the solution with input from `io/input.txt` and writes to `io/output.txt`.
    *   Command: `node main.js < io/input.txt > io/output.txt`
*   **`npm run build`**: Bundles `main.js` and all dependencies into a single file `output.js` using `esbuild`. Use this file for submission.
    *   Command: `esbuild main.js --bundle --platform=node --outfile=output.js`
*   **`npm start`**: Runs `main.js` directly (useful for interactive testing or piping).

## 🛠 Development Workflow

1.  **Write Code**: Edit `main.js`. Implement your logic in the `solve()` function. Use the helper classes (e.g., `new PriorityQueue()`) as needed.
2.  **Test Locally**:
    *   Paste the problem's example input into `io/input.txt`.
    *   Run `npm run test`.
    *   Check `io/output.txt` for the result.
3.  **Bundle for Submission**:
    *   Run `npm run build`.
    *   Copy the content of `output.js` and submit it to the online judge (Codeforces, AtCoder, etc.).

## ⚠️ Important Notes

*   **Fast I/O**: The template uses `fs.readFileSync(0)` for fast input reading. This is crucial for Node.js to avoid TLE on large inputs.
*   **LeetCode**: For LeetCode, **do not** use the Fast I/O block or the `main()` function. Only copy the necessary data structures and your solution logic.
*   **BigInt**: Use `BigInt` for large integer arithmetic to avoid precision issues. The template includes `readBigInt()` helper.
